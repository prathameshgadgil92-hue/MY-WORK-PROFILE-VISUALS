# P. V. Gadgil & Co. — Digital Work Profile

This folder contains a self-contained static website suitable for GitHub Pages.

## Publish on GitHub Pages

1. Create a new public or private GitHub repository.
2. Upload `index.html` and `ca-india-logo.png` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

No build tool or external web dependency is required.

## Local preview

Open `index.html` directly in a browser. For the most accurate preview, serve the folder through any local static server.

## Important

Keep `index.html` and `ca-india-logo.png` in the same folder. Review all contact and professional particulars before publishing. The Professional Information Note is included in the footer.
